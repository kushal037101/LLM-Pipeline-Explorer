KEY CONCEPT Why Tokenization Shapes LLM Intelligence

Imagine trying to read a book where every rare or compound word is sliced into familiar puzzle pieces. The word "uncharacteristic" becomes "un" + "character" + "istic". Because the model recognizes each piece, it never encounters an "unknown word". However, numbers like 1234 might be split into 12 and 34, which is why LLMs sometimes make basic math mistakes!

Byte-Pair Encoding (BPE) merges the most frequent pairs of adjacent bytes iteratively until the target vocabulary size $V$ is reached. Tokens serve as row indices into the embedding lookup matrix $\mathbf{W}_e \in \mathbb{R}^{V \times d_{\text{model}}}$. Smaller vocabularies increase sequence length $T$ (costing $\mathcal{O}(T^2)$ in attention memory), while excessively large vocabularies result in sparse, undertrained embedding vectors.

TECHNICAL NOTE Dimensionality Reduction (High-Dim → 3D)

Real AI embeddings have hundreds or thousands of dimensions (like 1,536 numbers per word!). Since human eyes can only see in 3 dimensions, we use a mathematical camera lens (PCA) to flatten the 16-dimensional semantic coordinates down to 3D, keeping similar words close together.

Given embedding matrix $\mathbf{X} \in \mathbb{R}^{N \times D}$, Principal Component Analysis computes the eigenvectors of the covariance matrix $\mathbf{C} = \frac{1}{N}\mathbf{X}^T\mathbf{X}$. Projecting onto the top 3 eigenvectors $\mathbf{W}_3 \in \mathbb{R}^{D \times 3}$ yields $\mathbf{Y} = \mathbf{X}\mathbf{W}_3$, maximizing preserved variance while maintaining pairwise cosine distances $\frac{\mathbf{u}\cdot\mathbf{v}}{\|\mathbf{u}\|\|\mathbf{v}\|}$.

CORE MATH Why Cosine Similarity Beats Euclidean Distance in AI

Imagine two arrows pointing from the center of a clock. If both point toward 12 o'clock, their meanings match, even if one arrow is much longer than the other. Cosine similarity measures the angle between ideas rather than their magnitude, ensuring a short sentence and a long paragraph about the same topic are recognized as matching.

Cosine similarity is defined as $\text{sim}(\mathbf{u}, \mathbf{v}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \cos(\theta)$. Because it normalizes vector lengths to the unit sphere ($\mathbb{S}^{D-1}$), it remains invariant to document length or token frequency scaling, making it ideal for high-dimensional vector search.

ALGORITHM DEEP-DIVE The Q, K, V Attention Formulation

Think of Self-Attention like a search engine:
• Query ($Q$): The question a word is asking (e.g. "it" asks: "Who am I referring to?")
• Key ($K$): The tag or label every word advertises (e.g. "cat" says: "I am a furry animal", "tired" says: "I am a feeling")
• Value ($V$): The actual detailed meaning transferred when a Query matches a Key!

Given input representations $\mathbf{X} \in \mathbb{R}^{T \times d}$, projection matrices compute $\mathbf{Q} = \mathbf{X}\mathbf{W}_Q$, $\mathbf{K} = \mathbf{X}\mathbf{W}_K$, $\mathbf{V} = \mathbf{X}\mathbf{W}_V$. The Scaled Dot-Product Attention equation is: $$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^T}{\sqrt{d_k}} + \mathbf{M}\right)\mathbf{V}$$ Where $\mathbf{M}$ is the optional causal autoregressive mask, and scaling by $\frac{1}{\sqrt{d_k}}$ prevents vanishing gradients in the softmax function for large dimensions $d_k$.

Tensor Shape Flow

Mathematical Formulation:
x_{out} = x + \text{Concat}(\text{head}_1, \dots, \text{head}_h)\mathbf{W}_O
Architectural Role:

Allows tokens to exchange information across the sequence. Each head attends to different relationships (grammar, coreference, factual ties). The residual skip-connection allows gradients to bypass the non-linear attention calculation without vanishing.

ARCHITECTURE Why Modern LLMs Use Decoder-Only Architectures

Older transformers had both an "Encoder" (reader) and a "Decoder" (writer). Modern models like GPT-4, LLaMA, and Claude use only Decoders because predicting the next token autoregressively turns out to be the most efficient, scalable way to master grammar, logic, and reasoning simultaneously.

Decoder-only models enforce a strictly lower-triangular causal attention mask ($\mathbf{M}_{ij} = -\infty$ for $j > i$). This guarantees that during pre-training, every position $t$ predicts token $t+1$ simultaneously without leaking future information, achieving optimal training throughput on parallel GPU tensor cores.

SAMPLING MECHANICS How Temperature Shapes Probability Distributions

When Temperature is 0, the model always picks the single most likely word (like answering with 100% predictability). As temperature rises, lower-ranked candidates get a chance to be chosen, creating creative, diverse, and sometimes surprising sentences.

Given unnormalized logit vector $\mathbf{z}$, temperature scaling modifies the distribution via: $$p_i = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$ As $\tau \to 0$, $p \to \text{argmax}(\mathbf{z})$ (greedy argmax). As $\tau \to \infty$, $p \to \text{Uniform}$, flattening probability across all vocabulary tokens.

About & Architecture

LLM Pipeline Explorer 2.0 Architecture

A production-quality, standalone educational platform crafted without build tools or external server dependencies.

Platform Specifications
  • • Architecture: Single-file reactive vanilla web application (`index.html`).
  • • Rendering Engine: Three.js WebGL (r128) + 2D HTML5 Canvas Software Rasterizer Fallback.
  • • Tokenizer: Greedy subword / Byte-Pair Encoding approximation with 50K vocabulary simulation.
  • • Embeddings: 16-dimensional deterministic semantic vectors projected via simulated PCA.
  • • Attention: Multi-Head Scaled Dot-Product Attention graph and dynamic heatmaps.
  • • Inference: Autoregressive streaming token generator with Temperature & Top-P nucleus sampling.
